# خوانا — Interview Runner

یک ابزار مستقل و سبک برای اجرای مصاحبهٔ فنی در **دو تب روی یک مرورگر**. به Reader اصلی خوانا دست نمی‌زند.

## راه‌اندازی

از ریشهٔ مخزن اجرا کنید:

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

سپس در مرورگر وارد `http://127.0.0.1:8765/interview/` شوید.

1. فایل **خصوصی JSON** بانک سؤال‌ها، پاسخ‌ها و Hintها را در پنل مصاحبه‌گر Import کنید.
2. روی **تب کاندیدا** کلیک کنید و فقط همان تب را Screen Share کنید.
3. سؤال‌ها را از پنل مصاحبه‌گر عوض کنید. Hintها و سؤال‌های پیگیری به‌صورت یک‌به‌یک نمایش داده می‌شوند.
4. پاسخ مرجع و Rubric را فقط در پنل خود باز کنید، نمره و یادداشت بنویسید و در پایان خروجی JSON ارزیابی بگیرید.

در تب کاندیدا **فقط سؤال جاری، شمارهٔ سؤال و تعداد سؤال‌های باقیمانده** به‌علاوهٔ Hintهای آزادشده نمایش داده می‌شوند. فهرست سؤال‌ها، نمره‌ها، یادداشت‌ها و پاسخ‌های مرجع منتقل نمی‌شوند.

## حریم خصوصی

ریپازیتوری عمومی است: **هرگز بانک سؤال خصوصی، پاسخ‌ها یا خروجی ارزیابی را به GitHub Commit نکنید**. فایل JSON را روی دستگاه خودتان نگه دارید. در کد Frontend فقط متن سؤال و Hintهای نمایش‌داده‌شده با `BroadcastChannel` بین دو تب هم‌مبدأ ردوبدل می‌شوند. داده‌ها به سرور خارجی ارسال نمی‌شوند.

برای عملکرد صحیح Sync، هر دو تب را از یک آدرس `http://localhost` و یک پورت باز کنید؛ از `file://` استفاده نکنید.

جلسه و یادداشت‌ها در `sessionStorage` تب مصاحبه‌گر نگهداری می‌شوند؛ پس از Refresh باید JSON خصوصی را دوباره Import کنید. برای آرشیو حتماً Export بگیرید.

**محدودیت:** ابزار برای Screen Share تب روی همان کامپیوتر است، نه ارسال لینک از راه دور به دستگاه کاندیدا. به محافظت از خود دستگاه مصاحبه‌گر و فایل‌های محرمانه همچنان نیاز دارید.
